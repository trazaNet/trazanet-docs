# 💻 TrazaNet Web - Documentación

Portal administrativo de TrazaNet (Angular 19) para gestión centralizada.

## ✨ Características
*   **Dashboard**: Resumen de animales y lotes.
*   **Gestión**: Listados completos y administración.
*   **Mapas**: Ubicación geográfica de potreros (Leaflet).
*   **3D**: Visualizaciones avanzadas con Three.js.

## 🛠️ Stack Tecnológico
*   **Framework**: Angular 19 (Standalone)
*   **UI**: Tailwind CSS + Material / Custom CSS
*   **Gráficos**: Chart.js / ng2-charts
*   **Geolocalización**: Leaflet

## 🚀 Despliegue
La app está desplegada en **Vercel**:
URL: [https://trazanet-web.vercel.app](https://trazanet-web.vercel.app)

Para desarrollo local: `npm install` -> `npm start`
